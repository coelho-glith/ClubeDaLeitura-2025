# ClubeDaLeitura 2025

![](https://i.imgur.com/QFfEKEo.gif)

## Introdução

Clube da Leitura é um sistema em C# com o propósito de gerenciar um clube de leitura. Através de uma interface simples via terminal, o usuário pode cadastrar livros, revistas, amigos, controlar empréstimos e visualizar os registros organizados em listas pré definidas.

## Funcionalidades

- **Cadastro de Revistas**: Armazene e consulte informações de revistas e periódicos.
- **Registro de Amigos**: Registre os membros do clube que podem realizar empréstimos.
- **Gerenciamento de Empréstimos**: Empréstimos e devoluções com controle de datas.
- **Interface de Menu Interativo**: Navegação por menus via terminal com opções disponiveis.
- **Validações de Entrada**: Prevenção de erros por meio de verificações e avisos amigaveis.

### 1. Clone o repositório.
 
```
git clone https://github.com/coelho-glith/ClubeDaLeitura-2025
```
### 2. Abra o terminal ou o prompt de comando e navegue até a pasta raiz

```
cd ClubedaLeitura_2025
```

### 3. Utilize o comando abaixo para restaurar as dependências do projeto.

```
dotnet restore
```

### 4. Navegue até a pasta do projeto

```
cd ClubedaLeitura_2025.ConsoleApp
```

### 5. Execute o projeto

```
dotnet run
```

-----------------------------------------------------------

### Requisitos

- .NET SDK (recomendado .NET 8.0 ou superior) para compilação e execução do projeto.
